# StreamingChat

Потоковое AI-приложение-чат для iPhone **и Mac** в духе ChatGPT на SwiftUI. Ответ
ассистента появляется токен за токеном по мере генерации, с кнопкой **Стоп** для
прерывания на середине. Чаты хранятся в боковой панели и сохраняются между запусками.
Поддерживаются вложение фото, выбор модели и офлайн-режим на Apple Foundation Models.

Сделано за один рабочий день, преимущественно с помощью Claude Code (Opus 4.8).

## AI в приложении

- **Сервис:** OpenRouter — выбран потому, что работает из регионов, где Gemini/Groq
  заблокированы. Только бесплатные модели.
- **Выбор модели** в приложении (меню в чате, сохраняется):
  - **Auto** (по умолчанию) — умный fallback по цепочке моделей;
  - текстовые/vision-модели: ERNIE 5.5 Flash, Gemma 4 31B, Nemotron 3.5 VL,
    OpenRouter Free (авто-роутер). Для фото автоматически берётся vision-модель.
- **Офлайн-режим:** Apple Foundation Models (`LanguageModelSession`) на устройстве —
  без сети, iOS 26+/macOS 26+ (см. раздел «Сделано»).
- **Что делает:** разговорный ассистент. Сообщение отправляется в chat-completions
  OpenRouter с `stream: true`, ответ рендерится **токен за токеном** через
  Server-Sent Events; каждый ход передаёт всю историю для контекста.

## Сделано

- ✅ **Потоковые ответы** — токен за токеном через `URLSession.bytes(for:)` + SSE.
- ✅ **Кнопка Стоп** — прерывает генерацию (`Task.cancel()`), сохраняя полученный текст.
  Работает и в офлайне.
- ✅ **Несколько чатов** — список-история с аватарами, превью и временем; создание,
  удаление отдельного чата (свайп + контекстное меню) и «Clear All History».
- ✅ **Сохранение истории** — SwiftData (`Chat` + `Message`); переживает перезапуск.
- ✅ **Состояния** — индикатор набора, **баннер ошибки с Повторить** (нет сети /
  лимит 429 / фото не поддерживается) и пустые экраны.
- ✅ **Копирование и метки** — под каждым сообщением время · дата и кнопка копирования.
- ✅ **Вложение фото** — `PhotosPicker`, превью с удалением, сжатие (≤1024px, JPEG 0.7)
  через ImageIO, отправка в формате content parts (`image_url`, data URL), миниатюра
  в пузыре, хранение через `@Attribute(.externalStorage)`.
- ✅ **Версия для macOS** — нативная (не Catalyst) из тех же исходников, один
  мультиплатформенный таргет; Enter — отправка, Shift+Enter — новая строка, минимальный
  размер окна, сайдбар, светлая/тёмная тема. Min macOS 15.
- ✅ **Офлайн-режим на Apple Foundation Models** — при пропаже сети (NWPathMonitor) и
  доступной on-device модели автоматически переходит в офлайн с меткой
  «Offline · on-device»; есть ручной тумблер. Проверка `SystemLanguageModel.availability`
  (устройство/Apple Intelligence/загрузка модели). Весь код под
  `#if canImport(FoundationModels)` + `#available(iOS 26/macOS 26)` — **на iOS 18
  приложение работает без изменений**.
- ✅ **Светлая и тёмная тема**; **iPhone + iPad + Mac**.
- ✅ **Без настройки после сборки** — ключ встроен (обфусцирован), модель по умолчанию
  бесплатная; `./Build.command` собирает и запускает из чистого клона.

## Не сделано и известные баги

- **Нет симулятора iOS 18 на сборочной машине** — установлен только runtime iOS 26.5.
  Target сборки — **iOS 18.0**, iOS-26-only API изолированы через `#available`, но
  тестирование на симуляторе проводилось на iOS 26.5.
- **Офлайн-режим не протестирован вживую end-to-end** — Foundation Models требует
  реального устройства с включённым Apple Intelligence (симулятор обычно сообщает
  `unavailable`). Код собирается на обеих платформах, запускается без сбоев, все случаи
  доступности обработаны; живую генерацию on-device можно проверить на устройстве iOS 26.
- **macOS: скриншот не снят в CI-окружении** — нет доступа к дисплею, но приложение
  собрано и запускается нативно (проверено).
- **Бесплатные лимиты** — у бесплатных моделей общие дневные лимиты; fallback-цепочка
  это смягчает, но при сильном ограничении возможна ошибка «лимит API» (обрабатываемое
  состояние с Повторить).
- **Reasoning-модели не по умолчанию** — некоторые бесплатные модели стримят
  «размышления» в поле `reasoning`; модель по умолчанию — без reasoning, токены сразу.

## Как проверяли

- **Сборка обеих платформ** — `xcodebuild` под iOS Simulator и `platform=macOS`:
  **BUILD SUCCEEDED** без предупреждений.
- **Чистый клон, без настройки** — `git clone`, затем `xcodegen generate` + `xcodebuild`
  → собирается без ручных действий; `.xcodeproj` в репозитории нет.
- **Запуск** — iOS в симуляторе и нативный macOS; проверены главный экран, навигация и
  **живой стриминг end-to-end** (сообщение → ответ токен за токеном, видна кнопка Стоп).
- **Фото** — проверен формат запроса с изображением и выбор vision-модели (цепочка
  проходит сквозь 429 и возвращает ответ); миниатюра сохраняется после перезапуска.
- **Выбор модели** — метка модели в тулбаре, скрытие кнопки фото для text-only моделей.
- **Офлайн-режим** — сборка на iOS 18 (деплой-таргет) и на последней iOS; весь код
  Foundation Models под `#if canImport` + `#available`, приложение запускается без
  сбоев; все ветки `availability` обработаны. Живая on-device генерация — только на
  устройстве с Apple Intelligence (в симуляторе недоступна).
- **macOS** — `xcodebuild -destination platform=macOS`: BUILD SUCCEEDED; приложение
  запускается нативно (ad-hoc подпись из `Build.command`).
- **Сценарии ошибок** — `URLError.notConnectedToInternet → noNetwork`, `429 →
  rateLimited`, фото без vision → `imageUnsupported`; все с `ErrorBanner` и Повторить.

## Сборка и запуск

Двойной клик по **`Build.command`** в Finder — при необходимости установит XcodeGen,
сгенерирует проект, соберёт и запустит iOS-версию в симуляторе, а вторым шагом соберёт,
подпишет ad-hoc и откроет нативную macOS-версию. Без ручных команд в терминале.

Или вручную:

```sh
xcodegen generate
open StreamingChat.xcodeproj   # затем Run (⌘R), схема StreamingChat (iOS или My Mac)
```

## Безопасность: обработка API-ключа

Ключ **никогда не хранится открытым текстом** в исходниках или в таблице строк
скомпилированного бинарника. Он обфусцирован через XOR в два массива байтов (`pad` и
`obfuscated`, фактически одноразовый шифр-блокнот) в `Sources/Services/APIKey.swift` и
восстанавливается во время выполнения как `obfuscated XOR pad`. Перегенерация:

```sh
swift scripts/ObfuscateKey.swift "sk-or-v1-...."
```

Это обфускация, а не шифрование — она защищает от тривиального сканирования `strings`,
что и требуется в задаче.
