# CLAUDE.md — StreamingChat

Guidance for AI agents (Claude Code, Cursor, …) working in this repo.

## What this is
A ChatGPT-style streaming AI chat app for iPhone, written in SwiftUI. Single-day
build demonstrating effective AI-assisted development.

## Hard rules
- **Minimum deployment target: iOS 18.0.** Any iOS 26-only API MUST be guarded
  with `if #available(iOS 26, *)` and have an iOS 18 fallback.
- **No hand-edited `.xcodeproj`.** The project is generated by **XcodeGen** from
  `project.yml`. The `.xcodeproj` is git-ignored. To change build settings, edit
  `project.yml` and re-run `xcodegen generate` (or `./Build.command`).
- **Dependencies via Swift Package Manager only.** CocoaPods is forbidden.
- **Never commit the API key in plaintext.** It is XOR-obfuscated into bytes and
  reconstructed at runtime (see `Sources/Services/APIKey.swift`). Keep real keys
  out of git and out of `ai-logs/`.
- **Commit frequently** with small, meaningful messages — not one giant commit.

## Build & run
- `./Build.command` — generates the project, builds for an iOS Simulator, boots
  it, installs and launches the app. Double-clickable from Finder.
- Manual: `xcodegen generate && open StreamingChat.xcodeproj`.

## Architecture
- `Sources/App/` — app entry point, root view.
- `Sources/Models/` — SwiftData `@Model` types (`Chat`, `Message`).
- `Sources/Services/` — OpenRouter client (SSE streaming), API key obfuscation.
- `Sources/Views/` — chat list, conversation, message bubbles, state views.
- `Sources/Resources/` — asset catalog.

## Key technical choices
- **Streaming**: `URLSession.bytes(for:)` reading Server-Sent Events line by line.
  The stream runs in a `Task`; the **Stop** button calls `Task.cancel()`.
- **Persistence**: SwiftData (`ModelContainer` in the App, `@Query` in views).
- **AI provider**: OpenRouter (works from Russia where Gemini/Groq are blocked),
  a free model. Daily free-tier limits exist — don't burn them in testing.
- **States**: loading, error (no network / HTTP 429 limit) with a **Retry**
  button, and an empty state.
- **UI**: `NavigationSplitView` (chat list ↔ conversation), supports light & dark.

## Testing
- Build & run on the iOS Simulator (iOS 26.5 runtime present; target is iOS 18).
- Test offline behavior (turn off network) to verify the error + Retry flow.
- Verify `./Build.command` works from a clean clone.
