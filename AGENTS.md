# AGENTS.md — StreamingChat

Указания для AI-агентов (Codex, Cursor, Claude Code и т. п.), работающих в этом
репозитории. Эти правила идентичны `CLAUDE.md`; оба файла поддерживаются
синхронно, чтобы любой используемый агент читал одни и те же инструкции.

## Что это
Потоковое AI-приложение-чат для iPhone в духе ChatGPT, написанное на SwiftUI.
Сборка за один рабочий день, демонстрирующая эффективную разработку с помощью AI.

## Жёсткие правила
- **Минимальная версия (deployment target): iOS 18.0.** Любой API, доступный только
  в iOS 26, ОБЯЗАТЕЛЬНО оборачивать в `if #available(iOS 26, *)` с запасным вариантом
  для iOS 18.
- **Никакого ручного редактирования `.xcodeproj`.** Проект генерируется **XcodeGen**
  из `project.yml`. `.xcodeproj` в git игнорируется. Чтобы изменить настройки сборки,
  правьте `project.yml` и заново запускайте `xcodegen generate` (или `./Build.command`).
- **Зависимости — только через Swift Package Manager.** CocoaPods запрещён.
- **Никогда не коммитить API-ключ открытым текстом.** Он обфусцирован через XOR в байты
  и восстанавливается во время выполнения (см. `Sources/Services/APIKey.swift`).
  Держите настоящие ключи вне git и вне `ai-logs/`.
- **Коммитьте часто** — маленькими осмысленными коммитами, а не одним большим в конце.
- **Вся документация, комментарии в docs и сообщения коммитов — на русском языке.**

## Сборка и запуск
- `./Build.command` — генерирует проект, собирает под iOS Simulator, загружает
  симулятор, устанавливает и запускает приложение. Запускается двойным кликом в Finder.
- Вручную: `xcodegen generate && open StreamingChat.xcodeproj`.

## Архитектура
- `Sources/App/` — точка входа приложения, корневой view.
- `Sources/Models/` — типы SwiftData `@Model` (`Chat`, `Message`).
- `Sources/Services/` — клиент OpenRouter (потоковая передача SSE), обфускация ключа.
- `Sources/Views/` — список чатов, диалог, пузыри сообщений, экраны состояний.
- `Sources/Resources/` — каталог ресурсов (asset catalog).

## Ключевые технические решения
- **Потоковая передача (streaming)**: `URLSession.bytes(for:)` построчно читает
  Server-Sent Events. Поток выполняется в `Task`; кнопка **Стоп** вызывает `Task.cancel()`.
- **Хранение**: SwiftData (`ModelContainer` в App, `@Query` во views).
- **AI-провайдер**: OpenRouter (работает из России, где Gemini/Groq заблокированы),
  бесплатные модели с автоматическим fallback.
- **Состояния**: загрузка, ошибка (нет сети / лимит HTTP 429) с кнопкой **Повторить**
  и пустой экран.
- **UI**: `NavigationSplitView` (список чатов ↔ диалог), поддержка светлой и тёмной темы.

## Тестирование
- Сборка и запуск в iOS Simulator (установлен runtime iOS 26.5; target — iOS 18).
- Проверка поведения без сети (выключить сеть) для сценария ошибка + Повторить.
- Проверка, что `./Build.command` работает из чистого клона.
